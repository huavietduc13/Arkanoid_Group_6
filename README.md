# Gameplay
## Tính năng
- **POWERUPS**: Có 9 loại buffs và debuffs.
- **Các loại gạch**: Độ bền gạch khác nhau và có gạch nổ, gạch điện.
- **Âm thanh**: Có các âm thanh đa dạng, có thể điều chỉnh âm lượng.
- **Level**: Nhiều cấp độ chơi, có màn đánh boss.
